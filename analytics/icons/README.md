Icônes de l'écran d'accueil du téléphone : `studio` (page du créateur, /studio/) et `stats`
(statistiques, /stats ; aussi icône de l'onglet). Dessins en SVG, texte en Saira Condensed 800
(public/fonts) ; les PNG (180 px pour l'iPhone, 512 px pour les autres) en sont tirés avec cette
police et copiés sur le site par `scripts/build-studio.mjs`.
